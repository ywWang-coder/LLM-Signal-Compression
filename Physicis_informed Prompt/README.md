# Physics-Informed Prompt

## Introduction

In this repository, we provide the experimental results for various prompt configurations. Each prompt configuration covers 4 experimental settings, including two experimental scenarios (Static and Dynamic) and two compression ratios (1/16 and 1/32). We evaluated our prompts using two state-of-the-art large language models, Gemini 3.1 Pro and GPT-5.4 Thinking, and conducted detailed ablation studies on each prompt module. Additionally, we provide example results of our prompts on open-source large models, including Qwen3.5-397B-A17B, Gemma4-31B, and Qwen3.6-27B.

## Tips and Usage Notes

1. Due to the large volume of test data and various experimental scenarios, we provide a sequence of experimental results for each setting. Each sequence contains 5 consecutive frames of wireless signals. 
2. Our experiments strictly follow the experiment settings in the paper. The experiment for each frame of data includes two dialogue turns: compression and reconstruction. Contexts between different dialogue turns are independent.
3. We have disabled the option for the LLM to learn from and utilize past conversational history. **Please ensure this option is turned off when attempting to reproduce our results.**
4. For the first frame of each data sequence, we do not provide a previous frame. When reconstructing each wireless signal frame, only the **reconstructed** wireless signal frame from the previous time step is used as a reference. To ensure fair comparisons among different prompt configurations, we guarantee the use of identical data sequences under the same setting.
5. We selected one data sequence for testing in the static scenario, and one for each of the two compression ratios (1/16 and 1/32) in the dynamic scenario. Detailed raw data can be found in the `Evaluation/TestData` directory.
6. The `Evaluation` directory also includes a `CalculateNMSE` folder demonstrating how to calculate the Normalized Mean Square Error (NMSE) of the LLM's output. We use `Truth.txt` as the raw ground truth data, `reconstructed_matrix.json` is the resulting JSON file generated by the LLM, and `calculate_nmse.py` is the script used to calculate the NMSE value.

## Evaluation

We provide the Python script `calculate_nmse.py` to calculate the NMSE metric. You can run the script in the `Evaluation/CalculateNMSE` directory to verify the results.

**Usage Example:**
If you want to evaluate an LLM's reconstruction output (e.g., from a test case like `1450.txt`), simply copy the ground truth content of `1450.txt` and save it as `Truth.txt` inside the `Evaluation/CalculateNMSE` directory. Then, place the LLM's output response into `reconstructed_matrix.json` in the same directory. Finally, run the script:

```bash
cd "Evaluation/CalculateNMSE"
python calculate_nmse.py
```
This will accurately compute the NMSE between the ground truth (`Truth.txt`) and the reconstructed prediction (`reconstructed_matrix.json`), accounting for the quantization wraparound in physical spaces, and output the detailed error analysis.
